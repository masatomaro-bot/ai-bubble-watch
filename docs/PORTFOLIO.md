# ポートフォリオウォッチ

保有銘柄のPERが、過去5年の自分自身の範囲のどこにいるかを見る画面。
データは `docs/data/per_watch.json`、表示は `docs/portfolio.js`。

## 何が自動で、何が手動か

| 項目 | 更新 | 誰が |
|---|---|---|
| 株価、今のPER、過去5年の中での位置、週足ローソク、10週線・40週線、株価の枠 | 毎営業日(日次ワークフロー) | `technical-practice/per_watch.py` |
| 今期のEPSの幅(`eps_now`)、来年度の予想EPS(`frame`)、確定年度のPER(`series`の確定行) | 決算・コンセンサスが変わったとき | Claude(「ポートフォリオウォッチのEPSを見直して」) |

画面の先頭には「株価の日付(`asof`)」と「EPSの前提を確認した日(`eps_asof`)」を分けて表示する。
株価は毎日動くが、EPSの前提は決算まで変わらないため。

自動更新は `.github/workflows/technical_practice_daily.yml`(平日22:00 UTC)の中で動く。
yfinance の取得に失敗した銘柄は前回の値をそのまま残す。手元で試すとき:

```bash
cd technical-practice
python per_watch.py --dry-run   # 書き込まずに結果だけ表示
python -m pytest tests/test_per_watch.py
```

## EPSのルール:コア基準で揃える

1. **コア基準**:保有株の評価益・売却益、減損などの一時的な損益を除いた、本業の利益で計算する。
2. **求め方**:会社がコア利益(非GAAP・非IFRS)を公表していればそれを使う。
   なければ 営業利益 ×(1 − 実効税率)÷ 株数 で求める。
3. **基準を混ぜない**:足元(今期)・予想(来年度)・過去の分布は同じ基準に揃える。
   予想だけ非GAAP、過去だけGAAPのような混在は、今のPERを過去より低く見せる。
4. **見分け方**:純利益がEBITDAを上回る四半期は、本業以外の利益が入っているサイン。
5. **揃えられていない銘柄**は `core_checked: false` にする。画面に「コア基準:未確認」と出る。
6. **通貨**:予想EPSの通貨を必ず確かめる(香港上場株のコンセンサスは人民元建てが多い)。

## 会計年度が替わるとき(手動)

確定した年度のEPSで、その年度の週の行を `[日付, PER, null, null]` に置き換え、
`eps_now` を新しい年度の幅と開始週(`from`)に更新する。分布(下位10%・中央・上位10%)は
次の自動更新で計算し直される。
