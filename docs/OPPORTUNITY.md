# 機会ウォッチ（初版）

`docs/index.html#opportunity` に既存の地合い画面と切り替えるタブを追加。
既存の市場データ取得処理からイベントで最新・直前履歴を受け取る。
既存パイプライン・Google Sheets・GitHub Actionsの設定変更は不要。

## できること

- テーマETFの象限変化を、取得できた直前履歴の日付とともに表示。
- NVDA / GOOGL / AVGOの空の判断カードを初期配置。実際の保有・判断は推定しない。
- 銘柄追加、ストーリー投資／テクニカル売買の切り替え。
- 仮説、強まる条件、壊れる条件、根拠、反証、最有力シナリオ、価格条件、イベントを手動編集。
- 反証→確認日到来→条件進展→確認済みの順で最大3件の確認候補を表示。
- 条件状態・方向感は自己評価。TradingView確認済みも利用者が記録。
- ブラウザのlocalStorageに保存、JSONバックアップと検証付き復元。
- 読み込みエラー時に既存データを自動上書きしない。

## 範囲とデータ

業績・ニュース取得、VCP自動判定、AIによる投資評価、プッシュ通知、端末間同期は未実装。
既存JSONに監視銘柄の価格がない場合の補間は行わない。
市場データはすべて自動取得・未検証として表示。ETF象限から資金流入を断定しない。
条件に進展・確認済み・反証ありへ更新する場合は根拠入力を必須にする。
市場データがなくてもカード編集は利用できる。

保存した仮説は公開リポジトリへ送信しない。同じブラウザ・同じサイト内でのみ保持。
ブラウザデータの削除や端末変更前にJSONをバックアップする。
復元は確認ダイアログ後に現在のカードを置き換える。
