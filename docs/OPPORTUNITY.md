# 機会ウォッチ：AIを読み、自分で判断する

## 使い方

1. 「機会ウォッチ」を開き、銘柄のAI分析を読む。
2. 出典付き事実とAIの推測を分け、反証・崩れる条件・次の確認事項を確認する。
3. 必要なら「納得・保留・異論あり」を選ぶ。メモは任意。読むだけでも使える。

市場の期待との比較材料がなければ「不明」と表示する。AI分析の情報基準日から7日を超えると注意を表示する。判断した分析IDを記録し、新しいIDの分析に変わると再確認を促す。これはAI評価の表示であり、売買指示ではない。

## 今できること／未接続のこと

- 実装済み：AI分析JSONの表示・読み込み、出典リンク、個人の判断・メモ、分析更新時の再確認表示、バックアップ・復元。
- 未接続：決算・ニュースの自動収集、AI APIによる自動生成、日次の自動分析更新。
- `data/opportunity/latest.json` は空で配布している。実在銘柄のストーリーを捏造せず、「AI分析待ち」を表示する。
- `tests/fixtures/opportunity-analysis.json` は架空の検証データ。ページは自動で読み込まず、`demo: true` のファイルは取り込みを拒否する。

AI生成の準備と未決事項は [AI_STORY_SETUP.md](AI_STORY_SETUP.md) を参照。

## AI分析の取り込み

ページ下部の「AI分析ファイルの取り込み」を開き、専用形式のJSONを選ぶ。形式検証と置換確認の後、AI分析だけを置き換える。未登録銘柄は「銘柄追加」で表示できる。データ構造・参照ID・日付・HTTPSリンクを検証するが、出典の実在性や記述の真偽は自動検証しない。

取り込んだAI分析は、このブラウザ内の `opportunity-analysis-v1` に保存する。取り込み済み分析がある場合は配信ファイルより優先される。新しい分析を見るには新しいJSONを取り込む。現時点では配信への切替や端末間同期はない。

## 個人データの保護

- 個人の判断・メモは従来と同じ `opportunity-watch-v1` に保存。AI分析とは別。
- 旧版の仮説・根拠・条件は「以前のメモ・詳細な監視条件」に保持する。
- 旧版バックアップの復元にも対応。新版バックアップには判断・メモ・判断した分析IDも含める。
- バックアップ保存・復元は個人データ用。AI分析JSONは含めないため、取り込んだ元ファイルを別に保管する。
- 復元確認を承認すると現在の個人データを置き換える。キャンセル時は変更しない。
- 背景データ更新や別カードの保存で編集中のメモを消さない。ブラウザ終了・再読み込み前には保存する。
- 保存済み個人データが壊れている場合は自動上書きを停止する。
- APIキーをブラウザに保存・表示しない。個人メモをGitHubやAIサービスへ送信する機能はない。
- ローカル確認用サイトと公開サイトでは保存先が異なる。移行には個人データのJSONバックアップ・復元を使う。

## 検証

依存なしの検証：

```sh
node tests/opportunity.test.cjs
node --test tests/opportunity-analysis.test.cjs
node --check docs/opportunity.js
node --check docs/opportunity-analysis.js
git diff --check
```

DOM操作テスト（Node.js 22.22.2以上の22系、24.15.0以上の24系、または26以上）：

```sh
npm install --prefix tests
npm test --prefix tests
```

旧UIでは利用者のPCで表示・保存・復元・再読み込み・狭幅表示・市場データ連携を確認済み。AI中心へ改修した今回のUIは自動検証のみで、実ブラウザによる見た目とスマホ実機は未確認。マージ・公開前に新版で確認すること。
