# 財務の確認項目と外部リンク

各銘柄に注目する財務指標とその見方、決算等の出典・TradingViewチャート・ChatGPTへのリンクを追加しました。市場全体にもChatGPTとS&P 500チャートへのリンクがあります。

質問文の自動作成、質問候補、質問入力欄、コピー操作、URLによる質問受け渡しは利用者の希望で削除しました。質問は利用者がChatGPTで書きます。ChatGPTのリンクは通常のホーム画面であり、特定の会話へ戻る機能ではありません。現在の会話を使う場合は開いている会話タブへ戻ります。

財務の項目は確認の着眼点で、リアルタイム数値を取得する機能ではありません。既存の数値・チャートには資料の期間と出典を引き続き表示します。SBUXは報道資料の照合段階のため、リンクも公式決算と偽らず出典名を表示します。

API・自動送信・個人メモの読み取りはありません。外部サービスの利用条件・ログイン・利用制限は各サービスに従います。

# ストーリーから考える機会ウォッチ（2026-09-18 更新）

## 今回の主画面
SBUX・GOOGL・AAPL・NVDA・AVGOの5社について、顧客に選ばれる理由、収益構造、成長仮説、四半期実績、反証、次の確認事項を表示します。企業ボタンで切り替え、監視に追加して任意の判断・メモを保存できます。収録企業は買い推奨ランキングではありません。

## 数値とチャート
- USD百万の原数値を `docs/opportunity-stories-data.js` に保存し、画面では億ドルに換算（100で割る）。
- 売上とGAAP営業利益をそれぞれ前年同期と比較。別の指標同士・別企業の棒の長さは比較しません。各指標の棒はゼロ基準、両期間に共通の尺度。
- 前年同期比は (今回÷前年同期−1)×100。前年がゼロ・赤字・欠損の場合、伸び率を未収録と表示。欠損はゼロに変換しません。
- 営業利益率はGAAP営業利益÷売上。Non-GAAPの補足指標にはラベルを付けます。
- 2時点比較から加速・減速を断定しません。将来予想の線や架空の中間値は描きません。
- SBUXはReuters/Barron’s報道のみ照合済み。前年比は報道値、前年額とGAAP営業利益は未収録です。残り4社は各社の公式決算資料またはSEC提出を参照。出典リンクと対象期間は各カードに掲載。
- 成長仮説・反証は編集上の分析であり、会社の確約ではありません。現在株価・予想利益の照合は実装しておらず、割安さは未判定です。

## 更新方法と費用
追加の有料API・AI API・キーは不要。ストーリーと業績は同梱された編集済みスナップショットで、株価更新とは独立しています。新しい決算資料を確認し、数値・文章・出典・発表日・編集確認日とストーリーIDを一緒に更新してください。発表から120日超で過去資料として注意を表示します。新しい銘柄を監視に追加しても自動調査や文章生成は行いません。

## メモの互換性
既存の `opportunity-watch-v1` とバックアップ形式を維持。ストーリーの判断は `story:銘柄:決算期:編集版` のIDと保存します。旧ルール判定・別版への判断は残しつつ、読み直しを促します。企業切り替え・市場データ受信・別銘柄追加でも編集中の入力を保持します。

## 見た目
PR #28の配色修正を含みます。白背景に薄い文字色が残る問題を修正し、本文16px・補足14pxを基本に整理。企業ボタンは狭い画面で折り返し、本文と数値の2列は900px以下で1列、指標は540px以下で1列になります。

## 検証範囲
自動テスト32件（従来27件＋ストーリーの表示・判断保存/再読込・編集保持・復元・欠損/赤字計算など5件）。CSS構文と主要配色のコントラスト確認。実ブラウザのレイアウト・スマホ実機はローカルページへのアクセス制限により未確認です。

# 機会ウォッチ：入力せずに「見る銘柄と理由」が分かる

## 基本の使い方

「機会ウォッチ」を開くと、既存の日次市場データから最大3件の確認候補と理由が表示されます。分析ファイルの作成・取り込みや、仮説の手入力は不要です。

1. 自動表示された候補の「なぜこの銘柄を見るのか」「未確認・注意点」「次に確認すること」を読む。
2. 気になったら「監視に追加」。判断・メモは任意。
3. さらに企業材料を調べたい場合だけ「必要なときだけ深掘りする」を開く。根拠・日付・未確認事項をまとめた調査メモをコピーできる。

これは**ルールに沿った数値の説明**です。AIの投資ストーリーではありません。日次ジョブで市場データが更新されると、次回ページ読み込み時の候補も再計算されます。ページを開きっぱなしにした状態の定期更新はありません。

## 費用と通信

新しいAI API・有料API・契約・APIキー設定は不要です。この追加機能は既存ページの市場データと履歴を利用するだけで、外部サービスを呼び出しません。従来からある市場データ取得処理とGitHub Actionsはそのままです。既存の無料枠や提供条件を将来にわたり保証するものではありません。

AI分析ファイルの取り込み画面・自動読み込み・生成用CLIは今回の方針変更で削除しました。ブラウザに以前のAI分析データが残っていても削除・送信しませんが、新しい画面では使いません。

## 対象範囲

- 既存JSON内の `market_leaders`（RS上位20件）と `trend_template_leaders`（トレンド条件合格のRS上位20件）の和集合。重複を除外する。
- この画面が全米国株を新たに検索するわけではない。
- NVDA・GOOGL・AVGOなどを監視登録しても、上位リストにない銘柄の個別データは未判定。画面にその理由を表示する。
- 個人の監視登録はブラウザ内だけに保存され、サーバーの取得銘柄を変更しない。
- 今後監視銘柄全体へ広げる場合は、既存の取得データから個別指標を出力する拡張が必要。今回は日次処理を変更していない。

## 抽出ルール

| 確認する変化 | 条件 | 確認順の値 |
| --- | --- | --- |
| 50日線を下回った | 比較時点は上、今回は下 | 90 |
| 50日線を上回った | 比較時点は下、今回は上 | 80 |
| トレンド条件合格の上位表に掲載 | 比較時点の非空リストにはなく、今回はある | 70 |
| 上位表に掲載 | 比較可能な上位表に銘柄がなく、今回はある | 65 |
| RS百分位が低下／上昇 | 両時点に値があり、1ポイント以上変化 | 61 / 60 |
| 大幅下落 | 前日比 -3%以下 | 50 |
| 強い上昇 | 前日比 +3%以上、50日線より上、RS百分位90以上 | 40 |

複数条件に該当する場合は理由を併記し、最も高い確認順の値を使用。同点はRS百分位の高い順、さらに同点はティッカー順。最大3件を表示し、残りを含む該当数も表示する。これは確認の順番であり、利益確率や買い順位ではない。閾値の投資成績は未検証。

リストへの掲載は「市場全体で初登場」「今日初めてトレンド条件に合格」とは扱わない。表が上位件数に限定されているため。RSは既存システムの百分位で、本物のIBD RSレーティングではなく、計算母集団の変化にも影響される。

## 欠損・古いデータ・品質

- nullや文字列をゼロへ変換しない。同銘柄の過去データがない場合、50日線・RSの変化を判定しない。
- 日付が同日、逆順、7日超の間隔なら比較しない。比較データがなくても当日の騰落条件は判定できる。
- データ日から4日を超えた場合は過去データの参考表示と明示する。未来の日付では候補を表示しない。
- 前日比の絶対値50%超、1か月200%超、3か月500%超は候補から保留。企業行動や価格調整を確認するためであり、誤データと断定しない。
- 同じ銘柄について二つのリストの値が不一致、不正な型、範囲外RSの場合も保留し銘柄を表示する。
- 個別出来高、高値更新、ニュース、決算内容、割安さは取得済みJSONだけでは分からないので推測しない。
- 条件に合うものがなければ候補を無理に埋めない。

## 個人メモの互換性

保存キーは従来の `opportunity-watch-v1` のまま。以前の仮説・根拠・詳細条件は折りたたみ内に保持する。旧バックアップも復元可能。

バックアップ保存・復元は個人データ用。復元確認を承認すると現在のカードを置き換え、キャンセル時は変更しない。破損済みデータは自動上書きしない。背景データ更新・候補追加・別カード保存でも編集中のメモを保持するが、再読み込みやブラウザ終了前には保存する。

判断時のデータ日を記録し、次の日付・別の判定方式になった場合は再確認を促す。AI版での判断IDがあっても、その判断をルール版の同意として扱わない。メモを外部送信する処理はない。

ローカル確認サイトと公開サイトは保存先が異なるため、移行時はバックアップを利用する。
