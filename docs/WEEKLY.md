# 週間ウォッチ(2026-11-07追加)

毎日の地合いウォッチとは別に、週1回しか更新されない指標を重要度順に並べるタブ。
地合いページの最上部には「週次の警戒ランプ」(4つ)の帯を出す。

## 表示する指標(重要度順)

| 重要度 | 指標 | 出典 | 取り方 |
|---|---|---|---|
| 1 | 利益予想の修正(次四半期・来年の予想増益率) | FactSet Earnings Insight | A(PDFを解析) |
| 2 | EPSガイダンスの上方・下方の社数 | FactSet Earnings Insight | A(取れなければB) |
| 3 | ハイイールド社債の上乗せ金利(OAS) | FRED BAMLH0A0HYM2 | A |
| 4 | S&P500の予想PER(5年・10年平均はFactSetの公表値) | FactSet Earnings Insight | A(取れなければB) |
| 5 | 個人投資家の強気・弱気／VIX | AAII／Yahoo Finance | A(AAIIが拒否されたらB) |
| 6 | GDPNow | FRED GDPNOW | A |
| 7 | 金・原油の大口投機筋の買い越し | CFTC 公開API(Legacy・先物のみ) | A |

## 警戒ランプ(判定ルール)

1. 利益予想の下方修正：次四半期・来年の予想増益率が前週より下がった(両方＝点灯、片方＝注意。期の切り替わり週は比べない)
2. ガイダンスの下方修正が優勢：下方修正の社数＞上方修正の社数
3. 下方修正がAI以外へ広がる：B(日曜の予定タスク)がFactSetの本文から判定
4. 信用の悪化：HY OASが5年平均を上回る＝点灯、4週前より拡大＝注意

## A＋Bの分担

- **A**：`technical-practice/weekly.py` を GitHub Actions(`weekly_watch.yml`)が土曜09:30と日曜20:30(JST)に実行し、
  `docs/data/weekly.json` と `docs/data/weekly_factset.json`(FactSet各号の解析結果のキャッシュ)をコミットする。
  スプレッドシートの「週間ウォッチ」タブにも1行ずつ記録する。初回はFactSetの過去号を60週分さかのぼって埋める
  (手動実行で週数を変えられる)。
- **B**：日曜夕方のClaudeの予定タスクが、スプレッドシートの「週間ウォッチ_手入力」タブに1行追加する。
  列は `weekly.py` の `MANUAL_HEADER` のとおり(週の金曜日付／今週の一文／警戒3の点灯・未点灯と根拠／
  AAII強気・中立・弱気と調査週／FactSetの予想PER・平均・ガイダンス件数／出典メモ／記入者)。
  `weekly.py` はAで取れなかった項目だけをこのタブの値で埋め、Aの値は上書きしない。日曜20:30の実行で画面に反映される。

## 数字を作らない

取得できなかった値は空のまま「取得できなかった」と表示する。目安線は公表値か計算値だけを使う。
