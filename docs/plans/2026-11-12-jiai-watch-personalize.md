## 目的

地合いウォッチの前提を「全市場をスクリーニングして新規にリーダー株を買う人」向け（oniminetrade/IBD流）から、**AIインフラ集中・現金ほぼゼロ・動くなら入れ替えのみ・コアはストーリー崩壊でしか売らない**という自分のポートフォリオ向けに切り替える。

骨格（外部環境 → 本日の地合い → 回復ラダー → 指数ステージ → 警戒チェック）は残す。中心になる作業は削ること。追加は3つに絞る。

確認時点：データ日 2026-11-10 の `latest.json` を元にページをレンダリングして確認（全長は約12,000px）。

## 優先度1：自分の層の相対強度（入れ替え判断用）【最優先】

現金がないので、地合いを見る実用上の意味は「どの持ち株からどの候補へ回すか」にある。

- [ ] `rs_line_watch` の対象を差し替える。いまの対象は ARM・NET・ALAB で古く、しかも画面に出ていない
- [ ] 新しい対象は持ち株と対抗候補
  - 計算基盤：NVDA / AVGO / AMD / TSM（MediaTekは米国上場がないため扱いを検討）
  - 料金所：GOOGL / MSFT / AMZN / META
  - 中国：0700 / 2318（yfinanceで取れるティッカーを確認する）
- [ ] 層ごとに比率チャート（対SPXのRS線、22〜60営業日）を1パネルにまとめ、地合い判定の直下に置く

## 優先度2：削る・統合する

- [ ] **Market Leaders／トレンドテンプレート合格銘柄の2表**を地合いページから外し、機会ウォッチへ移す。地合いの確認はラダー5段目（RS上位20の過半が50日線より上か）の1行で足りる
- [ ] **ブレッドス数値の三重表示をやめる**。同じ値がラダー、前営業日比較カード、市場の幅の3か所に出ている。「市場の幅」（22日スパークライン付き）1か所にまとめ、前営業日比較セクションは廃止する
  - 補足：ブレッドスの日付を1日前に揃えた日は前日比が全部0になり、比較の意味がない（11-10がこのケース）
- [ ] **指数ステージカード3枚**（S&P500・NASDAQ・RSP）は、ステージの帯（いまここ）と週足警戒ランプだけを並べる。日足・週足チャートと条件表は折りたたむ（チャートの読みはTradingViewで行う）
- [ ] **テーマ代表銘柄を絞る**：残すのはAI計算基盤／料金所／データセンター建設（CAT＝代理指標）／電力・原子力／宇宙・防衛。バイオ・クリーンエネルギー・輸送・素材は外す
- [ ] 「ChatGPTを開く」リンクを削除する

## 優先度3：足す

- [ ] **資金調達環境のゲート**（コア層の判断用。2026-11-07に追加した「自己資金 vs 外部調達」の軸をページに反映する）
  - 米10年・30年利回り
  - 投資適格の信用スプレッドの近似（例：LQD/IEF）
  - 「借りて貸す層」の代理として、ORCL・CRWV・NBIS の等金額バスケットの対SPY比
- [ ] **外部環境に USD/JPY と金価格を追加する**。いまはFRB・原油・インフレの3枚で、4〜5枚になる

## 優先度4：直す

- [ ] **最上部に「今日の一文」を置く**：判定、いま越えるべき関門、週足警戒を1行にまとめ、「コア層：〇〇／トレンド買い層：開・閉」の形で示す（週間ウォッチの「今週の一文」と同じ扱い）
- [ ] **ラダーの「過半＝仮置き」を校正する**：`backtest/` を使い、過去の調整局面で各段がどの順で埋まったかを一度検証する。終わったら「仮置き」の注記を外す
- [ ] **ステージ説明文**の「O'Neil/ミネルヴィニ流で買いを狙うのはこの段階だけ」は、トレンド買い層だけに当てはまると明記する。コア層は別ルール（ストーリー崩壊でのみ売却）
